# StudentHub - Enterprise Student Management System

A production-ready, portfolio-quality Student Management System built using Java 21, Spring Boot 3, Spring Security, PostgreSQL, and React.js.

## Tech Stack Summary

- **Backend**: Java 21, Spring Boot 3.x, Spring Security 6.x, Spring Data JPA, Hibernate ORM, JWT, Lombok, Bean Validation, PostgreSQL
- **Frontend**: React.js, Vite, Tailwind CSS, Axios, Context API, React Hook Form, Recharts, Lucide Icons, React Hot Toast
- **Database**: PostgreSQL (Normalized Schema)

## Database Design (ER Schema)

The database consists of **14 tables** in 3rd Normal Form:
1. `users`: Master identity credentials.
2. `roles`: Role definitions (`ROLE_ADMIN`, `ROLE_FACULTY`, `ROLE_STUDENT`).
3. `user_roles`: User-Role Many-to-Many join table.
4. `departments`: Academic division assets.
5. `students`: Enrolled students details.
6. `faculty`: Teaching staff details.
7. `courses`: Subject curriculum records.
8. `course_faculty`: Course-Teacher teaching assignment table.
9. `student_courses`: Student-Course registration log table.
10. `attendance`: Daily student class presence tracker.
11. `marks`: Academic scoring journal.
12. `announcements`: Targeted news bulletins.
13. `notes`: Shared classroom resources files logs.
14. `refresh_tokens`: JWT refresh rotation entries.

Refer to the complete script at [schema.sql](file:///e:/StudentHub/studenthub-backend/src/main/resources/db/schema.sql) for constraints, indexes, and keys.

## Installation & Setup

### Prerequisites
- **Java JDK 21+**
- **Node.js v18+**
- **PostgreSQL 15+**
- **Maven 3.8+** (Optional, Wrapper script included)

### Step 1: Database Setup
1. Create a PostgreSQL database named `studenthub`:
   ```sql
   CREATE DATABASE studenthub;
   ```
2. The schema will be automatically generated by Hibernate DDL-Auto on start. To seed custom records, run the contents of `schema.sql`.

### Step 2: Backend Configuration
Configure environment variables or update `src/main/resources/application.yml`:
- `DB_URL`: JDBC connection string (Default: `jdbc:postgresql://localhost:5432/studenthub`)
- `DB_USERNAME`: Database login user (Default: `postgres`)
- `DB_PASSWORD`: Database login password (Default: `postgres`)
- `JWT_SECRET`: 256-bit+ secure base64 string for signing tokens.

Start the Spring Boot backend:
```bash
cd studenthub-backend
./mvnw spring-boot:run
```
The server will run on `http://localhost:8080`.

### Step 3: Frontend Configuration
Navigate into the frontend project, install packages, and boot the Vite server:
```bash
cd studenthub-frontend
npm install
npm run dev
```
The application will launch on `http://localhost:5173`.

## API Specifications

### Public Auth Endpoints
- `POST /api/v1/auth/register`: Public self-registration (Default: student role).
- `POST /api/v1/auth/login`: Email & Password credentials. Returns JWT Access and Refresh tokens.
- `POST /api/v1/auth/refresh`: Generates new Access token.
- `POST /api/v1/auth/forgot-password`: Generates reset token (printed in console logs).
- `POST /api/v1/auth/reset-password`: Validates token and updates password credentials.
- `POST /api/v1/auth/logout`: Revokes refresh token.

### Protected Admin Endpoints (`ROLE_ADMIN`)
- `GET /api/v1/admin/stats`: Get dashboard indicators.
- `GET/POST/PUT/DELETE /api/v1/admin/students`: Manage student enrollment directory.
- `GET/POST/PUT/DELETE /api/v1/admin/faculty`: Manage faculty members registry.
- `GET/POST/PUT/DELETE /api/v1/admin/departments`: Manage campus departments.
- `GET/POST/PUT/DELETE /api/v1/admin/courses`: Manage curriculum courses.
- `POST /api/v1/admin/courses/{courseId}/assign-faculty/{facultyId}`: Assign teacher.
- `GET /api/v1/reports/students/csv`: Export student registries.
- `GET /api/v1/reports/faculty/csv`: Export employee registries.

### Protected Faculty Endpoints (`ROLE_FACULTY`)
- `GET /api/v1/faculty/courses`: Fetch assigned teaching courses.
- `POST /api/v1/faculty/attendance`: Record/Update student daily attendance records.
- `GET /api/v1/faculty/attendance`: Fetch attendance sheet for course.
- `POST /api/v1/faculty/marks`: Record student academic exam scores (upsert marks).
- `POST /api/v1/faculty/notes`: Upload files study materials (Multipart file).
- `DELETE /api/v1/faculty/notes/{id}`: Delete course files.

### Protected Student Endpoints (`ROLE_STUDENT`)
- `GET /api/v1/student/profile`: View personal profile dashboard.
- `PUT /api/v1/student/profile`: Update profile photo or phone (Multipart file).
- `GET /api/v1/student/attendance`: Fetch attendance percentages logs.
- `GET /api/v1/student/marks`: Fetch complete grades card.
- `GET /api/v1/student/courses`: Fetch enrolled schedule.
- `GET /api/v1/student/notes`: View and download shared slide files.

## Security Framework

1. **Stateeless Architecture**: Requests authenticate by verifying Bearer JWTs via `JwtAuthenticationFilter`.
2. **Access Rules**: Method-level security annotations (`@PreAuthorize`) and security filter chain match patterns enforce strict role-based constraints.
3. **CORS policies**: Configured explicitly to reject cross-origin script injections while permitting React client request flows.
4. **Token Security**: Employs short-lived (15 min) access tokens and rotate-on-demand refresh tokens.
